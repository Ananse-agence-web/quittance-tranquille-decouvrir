## Ce site

- **Aucun cookie**, aucun outil de mesure d'audience, aucun traceur, aucune publicité.
- **Aucun formulaire** : nous ne collectons aucune donnée personnelle.
- La vidéo est hébergée sur ce site : aucun service vidéo extérieur n'est contacté.

Le service d'hébergement qui diffuse les pages enregistre, comme tout serveur web, des données techniques de connexion (adresse IP, page demandée, date).

## L'outil Quittance Tranquille

**Aucune donnée n'est envoyée sur un serveur.** Les informations de vos baux sont rangées dans le lien de vos rappels d'agenda, après le signe « # » : cette partie d'une adresse web n'est jamais transmise au site. Les quittances sont fabriquées sur votre appareil.

Détails dans la [politique de confidentialité de l'outil](https://app-quittance.ananse.fr/confidentialite/).
